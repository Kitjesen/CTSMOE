# 已知问题与结论边界
- Hip实际峰值历史上仍接近0.41rad硬限；默认0.12并不是内收最大允许值。
- 45036学生固定30秒平地样本：前进25.49m、累计侧偏1.86m、平均vx约.916（命令1）；起步12腿RMS峰.125、末段.113，机身约.43m。不是随机成功率；长距离方向保持和高度仍有改进空间。
- 连续新地形均级高不等于独立能力验收完成；到顶保留与旧课程随机回落统计不同。
- 物理成功、跟踪通过、平台到达和连续稳定支撑不是同一指标。
- 仿真刚性轮胎不表达真实轮胎压缩、电气保护、BMS掉电；接触力大峰值不能直接作为实机定量结论。
- 旧录像曾出现渲染mesh叠放/字幕把轮角计入姿态RMS问题；已撤回的展示不用于验收。
- 归档的历史脚本存在硬编码路径与有意失败测试，不能批量运行所有历史driver。
