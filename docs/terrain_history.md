# 地形调整与复用
原始八类：平地、上楼、下楼、上坡、下坡、粗糙坡、波浪、障碍块。中期增加高台形成九类；V29后高台训练配额为0。
早期波浪出生按附近最高点抬高造成落地冲击，后修正出生贴地；历史失败不能一概解释为穿越能力不足。
坡面课程扩展至5/10/15/20/25/30/35/40/42.5/45°。等级仅代表训练采样强度。
V21加入上下楼外圈平台，保留内区但总阶数/总爬升改变；旧路线4m通过与平台末端稳定需分开。
V30在五个楼梯列加入单级上坎、短踏面上楼、长踏面上楼、坡接楼梯、短踏面下楼。短踏深25cm、长35cm、0–9级阶高5–20cm；参考楼梯同等级不一定同阶高。
V33增加六类，分配20%环境。最高连续坎/凸块40cm，坡45°、组合楼梯30cm，左右高差20cm，横坡14°加15cm凸块。训练台阶过渡带水平宽3cm，不能称精确垂直立面。

## 预览与训练网格区别
history/receipts/continuous_routes_v33_candidate/assets 是长路线设计模型与网页。
实际训练使用 src/thunder_v33/route_geometry.py等continuous模块（以目录清单为准），9×9m格子、课程及原点约束。长路线OBJ不等于训练用紧凑网格。
新路线要全身越过末障碍、root到3.3m终点、平均三轴跟踪误差达标、无物理失败/边界越界才计完成。原地形和新地形到顶处理不同，均级不能直接横比。

保留 geometry/runtime 测试、FROZEN清单和迁移收据；其他训练使用时明确机器人包络、轮距、出生高度、接缝、回合时长和晋级距离。
