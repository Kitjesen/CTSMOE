# 速度与启停调整
- 官方普通命令每5秒重采样、25秒回合。官方“zero”分支只清vx/vy，不保证yaw=0；我们的后续stop实现改为三轴0。
- 早期14120轮提前启用官方20000阶段：平移±0.5扩大±1.0m/s，yaw±1扩大±1.5rad/s；这是用户授权时机变化。
- V10/V11短起停试验曾使大部分样本很快进入零命令，不能当完整长跑训练；V12恢复25秒/5秒并撤回平地4秒/3米截断。
- V13重置位置目标同步实际q，清速度/effort目标；直接阶跃与渐变分开验收。
- V19平地20%固定队列采用动5/停5/动5/停5/动5秒；其他队列前进20%、后退10%、左右各10%、左右yaw各10%、4类组合各5%、全零10%。首次运动半直接半0.2秒渐变。
- V20扩大平地非零绝对值：vx0.1–2、vy0.2–1m/s、yaw0.2–1.5rad/s；符号由类别决定，不是只前进。不扩大所有地形。
- V29保留平地全向，楼梯直行/前进+yaw/前进+侧移短脉冲。
- V31五类新楼梯路线：直行/后退40%、纯侧移20%、前进+yaw15%、前进+侧移15%、组合10%；脉冲vy±0.15、yaw±0.25、持续3秒。原参考楼梯作为对照。
- V32按用户要求将纯侧移跨阶关闭，直行/后退60%，两个复合各15%、组合10%；初始heading25%对齐、75%在±45°随机。平地纯侧移/纯yaw仍训练。
- V33新增六类连续路线先vx0.4–0.9，vy/yaw0，初始±5°，5秒重采样；没有把普通楼梯±45°照搬到窄新路线。

实际实现与配置在当前源码中搜索 omni_commands、stop_commands、mixed_stair、omni_stair、initial_yaw、continuous。继承字段max_command_x不一定是最终覆盖后的采样上限。训练类别概率不等于时间占比或成功率。
