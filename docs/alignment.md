# 与固定 Go2 lab3.0 配置对齐

对照版本为 `6c95d9feef4814c25eb6536e61bb38e1d1d718d4`。复用其网络、PPO/蒸馏、命令采样器及奖励权重课程；机器人与用户已经确定的训练边界保持 Thunder 语义。以下是已接入的配置，不是运动效果结论。

| 项目 | 当前从零任务 |
| --- | --- |
| 环境数量 | 默认 16384，与官方相同；CLI 仅在显式提供 `--num-envs` 时覆盖 |
| 策略 | 官方 CTS+MoE，8 专家、latent 32、75% teacher / 25% student 控制环境 |
| 训练参数 | 官方 24 步 rollout、5 epochs、4 minibatches、Adam lr 0.001、gamma 0.99、lambda 0.95、KL 0.01 |
| 探索/保存 | scalar 标准差、奖励裁剪 ±10、每 500 轮保存，与官方相同 |
| 总预算/回合 | 用户指定 20000 轮、20 s；不复制官方 100000 轮和 25 s |
| 控制/物理 | 50 Hz / 400 Hz，保留 Thunder 2.5 ms 步长；不复制 Go2 5 ms |
| Newton 接触/积分 | 与官方一致：implicitfast、njmax=300、nconmax=128、三角形对容量 250 万、每形状 margin=1 cm |
| 初始指令 | x/y ±0.5 m/s、yaw ±1 rad/s |
| 5000 轮后指令 | x/y ±1 m/s、yaw ±1.5 rad/s；不执行官方后续扩展到 ±4 m/s 的阶段 |
| 站立/边界 | 官方站立比例 0→10%（0–1500轮）、边界采样 20%、5 s 基础重采样及动态重采样 |
| 地形 | Thunder 原 8 类、10 行；从 L0 开始，方块起步幅值 1 cm；最高楼梯 25 cm、坡面 40° |
| 高度 | A 姿态最低轮触地几何目标 0.392444 m、容差 2 cm，局部地面参考限速与缺测屏蔽；权重 -1→-10（0–5000轮） |
| 垂直速度 | 复用官方权重课程 -2→0（0–1500轮）；楼梯运动时原有排除逻辑保留 |

命令阶段由 `common_step_counter // 24` 判断；5000 轮之前保持初始范围，达到阈值后在采样时推进。正式恢复在重置前恢复已保存计数，因此不把课程重新当第 0 轮。配置不在运行中被 `pop()` 修改。

## 每种地形的速度

除楼梯外，以下均受上面的全局阶段范围约束；表中是最终上限。它不是地形等级自动触发的速度课表。

| Thunder 地形 | Go2 对应类别 | x (m/s) | y (m/s) | yaw (rad/s) |
| --- | --- | --- | --- | --- |
| flat | flat | ±1 | ±1 | ±1.5 |
| pyramid_stairs（中心向外下楼） | stairs_down | +0.25～+0.5 | 0 | 航向反馈 ±0.2 |
| pyramid_stairs_inv（中心向外上楼） | stairs_up | +0.25～+0.5 | 0 | 航向反馈 ±0.2 |
| boxes | small_squares | ±1 | ±1 | ±1.5 |
| random_rough | 无完全相同类别，显式使用用户上限 | ±1 | ±1 | ±1.5 |
| hf_pyramid_slope | slope_down | ±1 | ±1 | ±1.5 |
| hf_pyramid_slope_inv | slope_up | ±1 | ±1 | ±1.5 |
| wave | wave | ±1 | ±1 | ±1.5 |

每步按当前位置裁剪指令；进入楼梯立即约束，离开后恢复尚有效的请求。零指令在楼梯保持零，不会被正速度下界变成爬行。动态站立预算使用该地形有效最大速度，已发命令按控制周期累计，避免用原采样速度高估楼梯限速后的应走距离。实走进度和命令预算分别记录，原有“跟踪、稳定、无腿接触且越过地形格”的升级判据未放宽。

## 姿态、奖励和隔离

| 腿 | Hip (rad) | Thigh (rad) | Calf (rad) |
| --- | --- | --- | --- |
| FR | -0.12 | -0.681629 | +1.656219 |
| FL | +0.12 | +0.683232 | -1.656161 |
| RR | +0.12 | +2.531736 | +1.538234 |
| RL | -0.12 | -2.531736 | -1.538234 |

实际配置保存完整精度。用户选择 A 严格匹配 Go2 的侧面角度：前大腿 45.980°、后大腿 57.426°，并非前后等角。四腿连杆长度相同仍会产生不同的垂直投影；水平机身下后轮比前轮高约 11.68787 mm。将前链克隆到同侧后链再重新求解同样的 A 目标角，该差仍约 11.68782 mm，不能据此修改 URDF 长度。

按当前 URDF，四条大腿关节间 3D 距离均 259.480731 mm，四条小腿均 253.395393 mm；局部 xz 投影分别 250 mm 和 242.682540 mm。A 的后大腿向下投影少 40.421297 mm，后小腿向下投影多 28.733487 mm，合计解释了约 11.68781 mm 轮底差。Go2 companion URDF 的原默认前后足底本身也相差 9.581912 mm。

保持 A 关节角不变时，纯几何上机身抬头约 0.921968° 可以让四轮底接近共面（剩余约 0.000064 mm）。这不是水平机身，也不含碰撞 margin 或承重；没有因此修改默认机身旋转、强制每步姿态或伪造轮地接触。

前左关节局部 z 相差 0.4 mm，同时有 x 坐标变化；连杆长度仍一致。左右微小电机角差补偿这些零位/安装方向差，不是机身侧倾。出生高度为 0.412444 m；与未膨胀模型最低轮触地高度相差 2 cm，碰撞双方 margin 可能吃掉这段间隙。当前高度奖励目标不是已经测得的承重高度。URDF、惯量、机械限位和 PD 未改。B 四轮共面姿态仅保留为对照，不再是新训练默认值。

高度参考沿用局部裁剪扫描思路，额外在台阶参考变化过快时限速/屏蔽；它不是轮地支撑平面。其他腿/轮力矩、功率、碰撞、速度奖励仍使用 Thunder 权重，未把 Go2 足端打滑奖励套给滚动轮。教师已有显式关节加速度、力矩及轮接触输入；学生的单帧 53 个值按 10 帧历史组成 530 输入。

未经验证的镜像增强、额外髋惩罚、观测噪声和质量/摩擦/增益随机化保持关闭。这是待验收的名义动力学基线，并非最终鲁棒训练配置。旧 19538 回放仍用旧姿态与 log-std runner；新的 scalar 模型从零初始化，旧诊断权重不得强行加载。源/配置/裁剪参数均参与恢复校验。

验证进度与原生证据见 [validation.md](validation.md)。新配置不能仅凭 CPU 测试或静态姿态证明平地与 L6/L9 通行改善。
