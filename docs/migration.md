# Thunder 从零任务：环境迁移边界

新任务 `Thunder-Newpose-Newton3-Fresh-v0` 使用 `ThunderFreshEnvCfg`；旧任务 `Thunder-Newpose-Newton3-v0` 保留旧检查点回放基线。两者都复用 Go2 的地形导入工具和 Isaac Lab 管理器，不另写物理循环。

环境代码位于 `source/thunder_lab3/tasks/thunder/`，网络配置在其中的 `agents/rsl_rl_cfg.py`，机器人资产在 `source/thunder_lab3/assets/`。本轮官方配置对齐、用户选择的 A 姿态和验证边界见[alignment.md](alignment.md)。

## 新任务与旧回放的差异

| 项目 | 旧回放配置 | 新从零配置 |
| --- | --- | --- |
| 初始地形行 | L0–L5 | L0；通过课程再升级到 L9 |
| 方块随机高度 | `[-g,+g]`，g 的范围 5–20 cm | 仍为 `[-g,+g]`，复用渐进曲线，g 从 1 cm 增至 20 cm |
| 腿目标裁剪 | ±100 rad 的宽范围 | 使用这份 URDF 各关节硬限位；不是新测得的机械限位 |
| 接触采样历史 | 5 ms × 3 | 5 ms × 4，覆盖一个 20 ms 控制周期 |
| 腿碰持续时间 | 历史窗口任一峰值 >20 N，就累计整个 20 ms | 按新到的物理样本从旧到新计时，低于阈值即中断；连续 20 个 5 ms 样本才达到 100 ms |
| 单格越界 | 继续走到全地形边界 | 跨出分配的 8 m 地形格即 timeout，防止邻格运动计入原地形成绩 |
| 真正翻倒 | 原有失败状态与腿接触规则 | 增加 projected gravity z ≥ 0 的终止；40° 正常爬坡不触发该条件 |
| 楼梯线速度跟踪核宽 | std=0.25 m/s | std=0.5 m/s，和其他地形一致；初始 0.5 m/s 误差的未加权奖励从 exp(-4) 变为 exp(-1) |

方块的 **45 cm 是每个格子的边长**，不是方块高度。相邻随机格最大落差仍可接近 `2g`，因此最高难度仍可能接近 40 cm；降低起步幅度不等于高难度方块已经可通过。地形高度是随机采样，具体行的实际数值应读取生成结果。

新任务采用 Go2 最大行进距离 >4 m 升级，目标距离完成不足一半且未升级则降级；课程前补计终帧位置与命令预算，支持前进、后退和侧移。旧正向/侧偏/无腿碰升级门槛移除，接触惩罚与终止保留。等级只反映课程位置，不代替安全通行验收。

新腿碰计时保留 >20 N 的持续接触阈值、100 ms 连续时长、≥500 N 单次峰值立即失败，以及 >5 N 的曾接触标记。旧窗口判据会把“每 20 ms 仅撞到一个 2.5 ms 样本”误记为整窗持续接触；新函数逐样本清零/累计，并防止同一控制步重复调用重复计时。它要求 eager 更新、每物理步一个样本、历史长度恰好覆盖一个控制周期，配置不满足时显式报错。该修正没有放宽物理阈值，也不代表腿部碰撞已经解决。

新课程标识为 `thunder_fresh_10level_v4_go2_aligned_a_2dp`，物理标识保持 `newton_mjwarp_triangle_v1`。早期 smoke 检查点保留作旧配置对照，不能接续为当前训练；实际步长/求解器/源码指纹也会拒绝此类恢复。

此前 3 轮 log-std 诊断检查点需使用对应版本源码回放，当前 scalar 模型不加载该权重。从零新基线使用新签名，不放宽恢复校验。原 V33 文件完整保存在 `archive/v33/`，不作为新任务入口。

## 地形与命令保留范围

共 10 行 L0–L9、20 列，单格 8 m × 8 m：

| 地形 | 占比 | 参数范围 |
| --- | --- | --- |
| 平地 | 10% | 有厚度的封闭平面，表面 z=0 |
| 普通金字塔楼梯 | 15% | 台阶 5–25 cm，踏面 30 cm，中心平台 3 m |
| 倒置金字塔楼梯 | 15% | 同上 |
| 方块 | 15% | 格宽 45 cm，中心平台 2 m，渐进振幅 1–20 cm |
| 随机粗糙地面 | 15% | 噪声范围从低难度渐进至配置上限 10 cm |
| 普通金字塔坡面 | 10% | 坡比 0–tan(40°)，中心平台 2 m |
| 倒置金字塔坡面 | 10% | 同上 |
| 波浪 | 10% | 振幅配置 2–10 cm，3 个波 |

中心向外运动时，普通金字塔从高处向下，倒置金字塔从低处向上；名称不是机器人相对运动方向。播放选项 `stairs_up` 对应倒置金字塔，`stairs_down` 对应普通金字塔。

速度采用完整 Go2 课程及各地形上限，详见[alignment.md](alignment.md)。初始 x/y ±0.5、yaw ±1；最终平地 x -4.5～4.2、y ±1、yaw ±3，上下楼梯 x/y ±1、yaw ±1.5。保留 Thunder 地形几何难度；默认16384环境，25秒回合，5ms物理步长、50Hz控制，100000次更新预算。

已开启学生观测噪声、质量/增益/摩擦/零偏/推扰随机化和Newton构建前COM分桶；使用Thunder专用16动作镜像。真实参数读取与原生测试见[validation.md](validation.md)，不等同于旧PhysX分布的原样迁移。

## 奖励变更依据

共同奖励已对齐 Go2 Newton 权重与函数，保留轮专属奖励。新任务移除三项历史奖励：

1. `feet_contact_without_cmd` 使用首次触地事件计数，在零指令下给正奖励，不能代表持续支撑；移除以避免奖励反复落地。
2. `joint_mirror` 比较对角腿关节偏差的同号差；移除该奖励，采用独立验证坐标变换的左右数据增强。
3. `upward` 水平机身的原始数值为4，乘权重3得到12；新任务移除这个持续正项，速度跟踪使用Go2公式。没有据此声称已证明旧策略停留的根因。

不加入抬腿高度、腾空时长或Go2足端水平速度惩罚。轮子滚动不等价于足端打滑。独立hip L1权重-0.05，thigh/calf L1为-0.01，使用官方站立放大规则，替换旧整腿姿态/站立代价；高度目标仍为A两位小数几何值0.391415m、容差2cm。教师轮接触输入为净法向力的模，不等价于竖直承重或总接触力。

## 验证

在既有 Isaac Lab 3 Linux 运行环境中，从项目目录运行：

```bash
python -c "from isaacsim.asset.importer.urdf import URDFImporter; import unittest; r=unittest.TextTestRunner().run(unittest.defaultTestLoader.loadTestsFromNames(['tests.test_env_contract','tests.test_height_curriculum'])); raise SystemExit(not r.wasSuccessful())"
```

测试覆盖旧配置隔离、课程阈值、真实翻倒与正常坡面区分、完整接触历史、奖励项差异、固定楼梯等级回放、命令约束、模型重置接口、渐进方块曲线及高度参考的缺失值/台阶跳变。

腿碰回归还覆盖稀疏脉冲不累计为连续接触、39/40 样本边界、500 N 峰值、配置不匹配、重复调用与局部环境重置。

源码和 CPU 测试不证明步态或通行改善。新默认站姿尚未验收；这次没有修改 URDF 的机械范围。随机策略短训练只能验证优化器与环境链路，正式训练前仍需承重/动作/接触检查。
