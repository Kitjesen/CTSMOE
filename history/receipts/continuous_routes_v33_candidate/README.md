# 连续障碍候选生成器
参数代码为几何真源，Blender用于导入检查及视觉设计。OBJ三角形与预定碰撞表面来自同一网格；单位米，Z向上，X为路线方向。尚未进行Blender或Isaac导入验证，尚未接入训练。

assets包含9个OBJ（前4个连续路线和5个不对称变体）及各自JSON尺寸/随机种子/事件位置/SHA256记录，profiles.png从同一顶面坐标生成。第二幅40cm为高度上限，随机实际块高低于该值。示意图横纵轴显示比例不同，不以画面量取坡角。

生成：python export.py。测试：python -m pytest test_routes.py -q；ruff check .。16项测试通过，检查闭合、三角形非退化、坡度、相邻高差、出生平地及种子复现。不等于物理接触测试通过。

重要接入约束：样例路线10至14米左右，0.3m/s按完整路线计算已超过25秒；必须依速度与必要停滞裕量安排回合预算或分段课程。样例宽6米，不足以支持全程不转向的45度斜线；需扩大通行宽度或显式轨迹指令/角度课程，不能直接照搬V32±45度初始化。JSON记录宽度需求与保守角度界限，但机器人实际碰撞包络仍需仿真核验。

当前V32冻结训练保持原样。本目录仅设计和CPU几何验证，无GPU训练启动或实机发布。

新增资源、配额与接入方案见 TRAINING_PLAN.md。运行 package_resources.py 生成仅含地形资源的上传包和SHA256清单。尚未上传GitHub。
