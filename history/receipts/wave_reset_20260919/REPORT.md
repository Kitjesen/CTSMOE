# 波浪出生高度修复与正式训练切换

日期：2026-09-19。用户明确要求修复波浪出生悬空后落地超速的问题。本次修复了波浪重置高度的计算，完成几何、运动和训练恢复验证后接续原正式训练。并未取消执行器违规终止。

## 实现

旧 reset 使用地形中心区域最高点加默认根高度与 0–0.2 m 随机增高；最高点可能不在轮子脚下。此前 L9 名义起步样本在约 0.20 s 首次接触地面，同时左后小腿超速，前进不到 1 cm。

新增 `wave_surface_v1`，仅作用于分配到波浪地形的环境：

1. 保留原来的关节、XY位置、朝向和根速度抽样。新的事件排在 `reset_robot_joints` 和 `reset_base` 之后。
2. 从运行资产的 URDF 读取实际碰撞盒与圆柱，包括机身、腿、轮和有碰撞体的固定附件。根据已经重置的关节位置和根姿态进行批量正向运动学，不读取尚未刷新的刚体姿态，不额外推进仿真。
3. 用 2 cm 间距采样碰撞表面（当前模型 8,440 个点），向实际训练地形射线查询高度。计算使所有采样点距地面至少 **3 cm** 的最小竖直平移，替换波浪的根高度。必要时也会上移，避免随机姿态穿地；不会只按轮中心向下平移。
4. 普通重置的 0–20 cm 随机增高不再叠加到波浪最终出生高度。其他地形的 reset 不经过高度修改。

3 cm 是碰撞表面的竖直间隙目标，不是机身高度，也不是四个轮子同时贴地。地形起伏或随机关节姿态可能使其他轮子仍离地；若机身/腿先限制下降，则保留它们的间隙。

修改文件：`reset_geometry.py`、`wave_reset.py`、`train.py`；新增 `test_reset_geometry.py`。训练入口 `--wave-reset-profile wave_surface_v1`，不指定时从检查点继承，旧检查点默认 `original`。检查点、运行回执与逐轮状态记录该 profile，学生导出的 `training_context.json` 也记录它。冻结测试/回放若直接构建环境，应读取该上下文或显式启用相同 reset；执行器契约继续独立保存。

本次没有改变扭矩120/17 N·m、速度预算15/30 rad/s及违规终止、目标变化上限0.24 rad/步、奖励、地形几何、环境分配或速度课程。

## 几何与随机重置验证

- 96环境中80个波浪、8个上楼、8个下楼，覆盖0–9级；重复8次，完成 **640次随机波浪重置** 和 **128次楼梯重置**。保留训练中的关节缩放0.5–1.5、XY ±0.5 m、随机Yaw、根速度等范围。
- 正向运动学与仿真刚体位置比较，最大误差 **0.0000229 m**，约0.023 mm。
- 用更密的 **5 mm间距、121,160个碰撞表面点** 独立复查，最小竖直间隙 **0.0280 m**，未发现穿地。这是对已测样本和离散碰撞表面的验证，不是所有连续姿态的数学证明。
- 640次中有1次因非轮碰撞体限制下降，最近轮表面仍距地约10.6 cm；其余绝大多数最近轮约3 cm。没有为了强行让轮接地而把机身或腿压入地面。
- 在楼梯环境调用修复事件，根状态逐位相同；没有修改楼梯出生方式。

原始证据：[geometry_validation.json](geometry_validation.json)，脚本 [validate_geometry.py](validate_geometry.py)。

## 同策略运动对照

冻结25,501次更新检查点，教师/学生各36次：L0/L3/L6/L9 × 0.3/0.6/0.9 m/s × 3次重复。沿用上一轮完整名义条件矩阵，同样的12 rad/s目标变化率、全部执行器保护、25秒上限和前进4 m出口；无学习、无航向反馈、无观测/参数/推扰随机化，保留执行器延迟。检查点的历史profile为v2，两组均显式将目标变化率设为12 rad/s，与当前v3数值相同。

| 指标 | 原出生高度 | 修复后 |
| --- | ---: | ---: |
| 教师4 m通过 | 26/36 | **30/36** |
| 学生4 m通过 | 25/36 | **32/36** |
| 教师最初0.35秒失败 | 5 | **0** |
| 学生最初0.35秒失败 | 6 | **0** |

已匹配场景、起始XY、姿态和轮相对根位置，确认初始差别为Z平移；逐控制步验证两组真实动作投影都是0.24 rad。修复后学生仍有3次执行器违规终止、1次机身触地；教师仍有1次执行器违规、3次机身触地、2次超时。它们是剩余运动失败，不能用起步问题已修复来掩盖。

这组32/36应与**同为0.24 rad/步**的25/36比较。此前固定降低10 cm得到35/36的测试使用0.12 rad/步，且使用不同出生高度算法，不能混为同一单因素对照。

证据：[motion_comparison.json](motion_comparison.json)、[surface_rate12/results.json](surface_rate12/results.json)。
