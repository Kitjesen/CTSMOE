# V9起步退化：历史、跨地形与实际奖励账本

## 已确认的结论

1. V9的异常不是高台专属。在44,711轮的83个学生固定场景中，九类地形都有较大的起步角度偏移；平地、楼梯、坡与障碍块在0.6m/s下高度相似。非平地通行成功不等于起步姿态合格。
2. 异常并非越快越严重。同一上坡L6，V9学生0.3/0.6/1.2m/s的首秒RMS峰值为0.0900/0.4195/0.1576rad；教师为0.0915/0.4200/0.1553。V6为0.0931/0.1392/0.2042。现有离散速度测试只能确认0.6指令异常，尚未做其附近的密集速度扫描。
3. 新的统一奖励回放直接否定了“这次坏平地起步比V6更赚”的说法：V6前1秒实际总回报1.951，V9仅0.035；前2秒为4.251与0.722。不能把训练后保留某动作解释为该动作真实回报更高。
4. 高台/楼梯混训是有依据的诱因假设，不是已隔离证明的唯一原因；共享网络、跨任务奖励强度差异、没有V6行为保持目标，均可造成旧能力退化。尚未测量分地形梯度冲突或完成同源单因素消融。

## 从何时开始

历史报告 `../posture_history_20260920/REPORT.md` 回溯34个检查点、172回合，将首次明显退化定位到31,831轮之后。首秒平均RMS（注意不是本报告的峰值）从31,831轮0.123升到32,001轮0.250、32,501轮0.462。同期高台爬升优先课程从25cm推进到45/60cm；高台占50%，专门平地仅94/4096。执行器profile与相关学习率未变。高度项更早关闭后仍曾长期自然起步，不能单独归因给高度项关闭。

V6在43,202轮曾恢复较好姿态。V8从V6恢复、保留平地奖励，但新增楼梯/高台阶段式奖励、平台几何与低台课程迁移；到43,501轮前进姿态已退化（全程峰值0.464rad）。这是第二次退化。另一V7分支也曾退化，因此不能断言V8阶段机制是唯一可能原因。

## 奖励账本：四策略按同一V9奖励比较

本次新增独立仿真，共332固定案例，V6、V8、V9学生、V9教师各83例，无优化更新。使用成熟V9权重、相同默认初态与评估协议；直接捕获RewardManager加权分项乘dt=0.02，并断言分项之和等于环境真实总奖励、记录命令等于奖励使用的命令、数值有限。

表内分项并非穷举；总计还包含力矩、加速度、原版L1等。所有高台专用奖励在此平地回合均为0。V9教师首秒总回报为-0.075。奖励管理器不把负总回报裁成0。新回放不是与旧评估逐帧完全相同：V9前1秒腿角最大差约0.020rad，RMS峰值0.417对旧值0.415；V6峰值0.132对旧值0.132。其他场景后续轨迹/终止也存在差异，不宣称全轨迹一致或由奖励记录证明确定性。

这些数据证明本次平地坏动作在测量片段更亏，不证明V6在全部任务、全时域或随机训练分布下回报一定更高；亦不是PPO优势、梯度方向或最优性证明。

## 机制与修正重点

当前PPO更新教师编码器、critic与教师/学生共享actor；学生独立优化器蒸馏的是正在变化的教师latent，没有冻结V6行为保持项。不同任务更新同一动作映射，不会自动保留旧检查点的优点。学生只有本体历史和命令，没有直接前方高度扫描；接触前相近观测难以分辨前方障碍。教师有扫描也发生异常，故仅加强学生蒸馏或仅归因缺少感知均不足。

V9只在明确flat标签使用新的连续实际姿态项；其他地形仍有死区/阶段释放，攀爬时原版L1缩放至20%。这是潜在的共享训练冲突源，不能在没有梯度或消融证据时给出单一根因比例。

已授权V10仍按既定1000轮实验执行，先处理平地集中大偏移，再做多地形回归。本次仅增加诊断，未修改正在运行的权重或课程。后续如果V10不达标，需要以保留V6正常起步行为、同源对照定位干扰为重点，而不能把无限加权或更多轮数当成已经成立的解决方案。
