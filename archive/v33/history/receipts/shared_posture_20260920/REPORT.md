# 九类地形共享策略的起步与站姿审计

2026-09-20。冻结学生检查点完成41,501轮；正式训练在独立进程中继续。

## 结论

高台、平地、上下楼梯、上下坡、波浪、粗糙坡和障碍块使用同一学生MoE编码器和动作网络。专家不是按地形独占的策略；教师也使用共享动作网络。高台训练会更新共享参数，但本次未进行加入高台前后的匹配对照，不能据此断言异常全由高台训练造成。

并非所有地形都持续低趴。确认的共性问题是从重置状态立即给前进指令时，多种地形出现很大的腿姿偏离；平地随后能够恢复较正常的行走。高台登顶后持续低趴是另一个仍需训练纠正的问题。能完成位移和地形等级较高，都不能替代姿态质量验收。

## 试验协议及边界

96个首回合：16组地形/等级 × 3种指令 × 2个重复。平地L0；上/下楼梯L0/L6；上/下坡L0/L5（5°/30°）；波浪L0/L6；粗糙坡L0/L5；障碍L0/L6；高台L17（1米）。

三种指令是全程零速、立即前进0.6 m/s，以及先零速2秒、前进至8秒、再零速至12秒。高台保留全身登顶后自动停车。以首次终止为准，不重试，不拼接重置后的回合。保留已有楼梯路线截断，并在世界坐标正X达到4米时停止观测，避免走进邻接地块。

关闭传感器噪声、动作采样、推扰和物理参数随机化。普通地形固定根部重置偏移和关节位置倍率，但楼梯仍保留四个轴向的随机朝向；高台仍保留自身出生扰动；波浪保留贴地重置。执行器延迟保留。原始manifest中“normal terrain reset fixed”概括不完整，以这段和修订后probe.py为准。

这是姿态诊断，不是完整训练分布下的通过率评测。重复样本很少，多个普通地形出生于中央平坦区域；爬坡/跨台阶时偏离默认站姿本来就可能必要。12秒观测预算和路线边界截断不算物理失败。

## 主要实测

腿姿误差为12个腿关节相对默认角度的RMS，轮关节不参与。

| 地形 | 立即起步首秒腿姿RMS，rad（样本范围） |
|---|---:|
| 平地 | 0.664–0.679 |
| 上楼梯 | 0.616–0.641 |
| 下楼梯 | 0.628–0.660 |
| 上坡 | 0.607–0.670，包含一个不足1秒的失败回合 |
| 下坡 | 0.648–0.669 |
| 波浪 | 0.549–0.659 |
| 粗糙坡 | 0.412–0.468 |
| 障碍块 | 0.640–0.677 |
| 1米高台 | 0.630–0.657 |

平地代表样本：

- 直接0.6 m/s起步：首秒RMS 0.679 rad、单关节最大偏离1.811 rad；1–2秒实际前向速度均值约1.377 m/s，出现明显超调，随后3秒以后的RMS降到0.251 rad、前向速度约0.589 m/s。
- 0.58秒时左后大腿默认−0.93 rad，实际−2.741 rad、目标−2.615 rad；策略目标本身偏离很大，不能仅归因于PD跟踪不够强。
- 先站2秒再起步：3–5秒RMS约0.240 rad，实际前向速度约0.603 m/s、四轮持续支撑。这个对照定位到启动状态/指令时序相关问题，不足以单独区分历史观测、接触建立和策略目标的作用，更不能直接推广为必须加两秒等待。
- 全程零速度时末2秒RMS约0.303 rad、机身离地约0.393 m；比高台持续低趴轻，但依然未恢复0.46 m默认高度，且有约0.05 m/s残余运动。

平地、低台阶、低坡和障碍样本仍能行进。不能用这批小样本宣称所有技能质量达标，也不能将它描述成所有动作都已退化为爬行。

## 已实现的补充训练目标

新增 `surface_posture.py` 的 `level_surface_v1`，默认关闭，正式启用后写入检查点并自动继承。高台已有的 `phase_stance_v1` 保留。

- 使用现有1.6×1.0米地形扫描的原始几何，不使用加噪后的策略输入，也不以机器人是否已经趴下决定启用与否。
- 普通地形扫描区域高差≤4 cm时完整启用，4–10 cm线性退让，≥10 cm关闭。高台环境完全排除，避免重复施加与妨碍攀爬。
- 指令平移速度≤0.8 m/s完整启用，至1.5 m/s线性退让；Yaw≤0.5 rad/s完整启用，至1 rad/s退让。高速和大转向仍沿用原有目标，需另行匹配评估，不能声称已经解决。
- 腿关节允许偏差为髋0.25、大腿0.45、小腿0.55 rad，超出带宽后的归一化平方均值权重−1；平坦支撑面相对机身高度目标0.46 m，按0.10 m归一化平方成本权重−0.5。
- 不覆盖策略动作，不增加停车等待，不收紧关节限位和扭矩/速度保护。全局高度惩罚保持0，非平坦区继续允许地形适应动作。
- 无效扫描不能定义支撑面，仅使新增几何姿态成本退出；既有接触、执行器和终止约束保留。新约束的启用数、姿态误差、离地高度、符合比例按地形记录。

这是一项针对已观测目标缺口的训练修正，不能把规则上线等同于学生已经学好。波浪/粗糙坡等非平坦区域经常退出此项约束；其动作质量仍需单独评估，未在本次全部解决。

## 验证与续接

24项相关pytest通过；受影响源代码和诊断脚本ruff通过。4096环境8次更新预检及2次更新断点继承成功，模型、PPO和学生优化器、分地形课程、地形分配全部恢复一致。预检证实普通平坦区域产生新成本，高台新成本启用数为0，全局高度惩罚仍为0。

正式续接点、PID和运行实测见 `switch_receipt.json` 与 `verified.json`。首次切换检查因完成后的status.json只保留简短完成状态而提前拒绝，尚未停止正式训练；检查脚本改读完整metrics.jsonl最后一行后才执行切换。

正式从41,647轮、model_41646.pt续接；核验完成41,654轮，PID 180992，单轮6.86秒，目标60,000轮，4096环境。10项状态继承检查全部通过，新目标在普通地形平坦区域启用，高台不重复施加；原高台分阶段目标保留。核验的混合训练快照中平台姿态条件符合率约70.5%，但它混合了教师/学生和不同高度、阶段，不能替代同一1米学生策略的独立匹配复测，也不能拿它直接宣称起步已修好。

后续效果验收应使用同一指令和出生条件，比较首秒目标偏离、速度超调、稳态姿态、停车残余速度，同时复测楼梯和高台通过，避免以改善姿态为代价丢失越障能力。
