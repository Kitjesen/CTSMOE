# 官方启停与姿态奖励对照

审查时间：2026-09-22。当前训练已在 33,034 轮保存停止；本轮只审查并提出修正方案，未启动新训练。

## 启停语义

核对服务器实际 upstream/mdp/commands.py 与 GitHub 当前 main。官方 resampling_time=5 s，回合内重新抽样；零平移概率参数在 0–1500 轮从 0 增至 0.1。该分支受剩余时间/距离条件约束，因此参数不是实际全回合时间占比。

关键实现：`self.commands[zero_env_ids, :2] = 0.0`，并未将第三维 yaw 清零。随后 20% 的该分支样本被赋予极限 yaw，其余保留之前抽样的 yaw。故代码注释“set all commands to zero”与实现不完全一致。不能将这段代码解释为 10% 完全停车，或 8% 停车 + 2% 纯转；当前普通采样继承相同语义。随机抽到很小 yaw 不等于明确的全零停车覆盖。

当前 startup_sampling.py 为部分平地正常初始化 cohort 提供十种显式运动方向（包含两种纯旋转），第一次命令的一半为直接阶跃，一半为 0.2 s ramp；5 s 后回原采样。十种类别中没有全零停车，也没有保证同一回合运动→停稳→再起步。高台登顶另有独立全零命令，但不能替代平地停车训练。楼梯和 V16 专项上坡使用保持前进命令，不能照搬普通采样的比例。

当前没有完整记录实际 full-zero/rotation/translation 的时间占比与转换计数。应新增这些指标后才报告实际覆盖率；本次是源码与配置审查，不虚构在线抽样统计。

## 建议的训练修正（尚未实施）

不需要立刻随机初始化清零重训。先用31,831检查点做修正分支，保留V6的姿态参考和33,034的诊断对照；31,831也非完美姿态或从未训练过高台，必须按同条件验收。调整目标后仍需要训练，单靠部署侧角度限幅不会改变策略学到的偏置。

保留全地形的弱连续默认角基线，将平地实际姿态加强项分阶段施加：

1. 平地站立：三轴全零后允许合理制动过程，再加强实际关节偏差及实际速度/角速度约束，避免命令刚归零就强迫瞬时收腿。
2. 平地运动：实际角连续L1加强，无大免罚区，无高速自动关掉；同时记录各关节极值，防止总和掩盖后腿。高度使用局部支撑面参照，避免把世界高度当腿伸展。
3. 接近高台或楼梯：远离障碍保持正常姿态；根据真实前方边缘距离、高差、支撑几何逐步减弱“额外”姿态/高度项，允许必要预备动作。不能因机器人自己下蹲、倾斜或速度变大就自动免罚。
4. 攀爬：保留弱基线、实际力矩/转速/限位等，释放额外平地约束。并非关节冻结在默认角也非无约束。
5. 完成越障：确认全身越过边缘、后轮完成跟进且支撑恢复后，平滑增强站姿约束。前轮上台或机身开始回正不能直接触发强恢复，以免末端弹跳。

表达式：r_pose = -sum_j [lambda_base_j + alpha(geometry, phase)*lambda_extra_j] * abs(q_j-q_default_j)。停车额外倍率要确认全零命令且给出制动过渡；alpha使用滞回与有限变化率。公式是设计，不是已经激活的代码。教师/学生共用相同任务奖励定义，不能只修学生输出。

启停覆盖：在部分平地环境中显式安排走→全零停→再起步，保持25 s回合，纯旋转独立类别；继续保留持续行走组。统计真实三轴全零比例、停走/走停次数、停车时长及剩余运动时长。此采样修正与奖励修正应分别做有界对照，不能把全部因素一起改后只看平均回报。

验收：每一腿关节的前1 s/1–5 s/后段偏差、目标首步和后续变化、制动距离和停稳时间；全向速度跟踪；楼梯末段竖直速度/姿态恢复；高台实际通过及最高高度。平地姿态改善不能抵消越障损失，单关节退化不能由平均RMS改善抵消。
