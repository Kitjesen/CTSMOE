# V21 本地 MuJoCo 预检约定

2026-09-23：用户要求本地 Hip 默认站姿从镜像 ±0.20 改为 ±0.12 rad。FR/FL/RR/RL 为 `[-0.12,+0.12,+0.12,-0.12]`；同一默认值用于 reset、相对关节位置观测和动作目标偏移。策略仍控制 Hip，不锁死在默认角度。原始训练 YAML/ONNX 保持原样，服务端历史行为评估对应原始 ±0.20 默认站姿，不代表这次修改后的表现。

2026-09-22 增加可选 `-Kp` / `-Kd`（Python 对应 `--kp` / `--kd`），仅覆盖本次仿真的 12 个腿关节。省略时腿部仍为训练默认 120/8，轮子始终保留 0/1。允许非负有限数值，报告 `pd_gains` 记录逐关节实际参数。`verification/smoke_pd_90_6p93.json` 为经 PowerShell 入口传入 90/6.93 的 3 秒加载验证，不能用于推断其他参数下的运动效果。

- 模型：`model_34822.pt`，完成 `34823` 次更新。ONNX 来源、完整 SHA256 和动态/静态数值比较见 `exported/export_verification.json`。
- 输入：float32 `history [B,530]` 和 `single_obs [B,53]`，输出 `actions [B,16]`。历史长度 10，按字段拼接，每个字段内由旧到新；第一帧重复填满历史。无外部 recurrent state 或额外 phase 输入。
- 当前帧：角速度 3×0.25、投影重力 3、速度命令 3、腿部相对默认角度 12、全部关节速度 16×0.05、上一 action 16。按训练约定先 clip 至 ±100 再 scale。
- 关节顺序：FR/FL/RR/RL，每腿 hip/thigh/calf，最后四轮 FR/FL/RR/RL。默认姿态、逐关节硬/软限位见 `deployment_contract.json`，没有套用 Flat 姿态。
- 名义 PD：腿 120/8，轮 0/1；action scale 腿 0.25、轮 5。腿目标变化率 12 rad/s，50 Hz 下每次最多 0.24 rad；轮目标 ±30 rad/s。力矩限幅腿 120 Nm、轮 17 Nm；腿保留 DC motor 速度-扭矩包络。
- 物理步长 0.005 s、decimation 4。监测实际关节速度，未强行裁剪仿真状态；v4 训练终止规则不代表物理硬限速。
- 载体复用先前 CTS MuJoCo XML 和键盘运行时，实际训练 URDF 哈希相同；包校验脚本再次核对关节轴、连接位置、限位、质量和楼梯尺寸。
- 场景：混合地形的 10/15/20/25 cm 楼梯，按用户要求改为踏步深 0.30 m，左右宽 6 m、顶部平台深 0.85 m，包含上楼、平台和下楼。其几何与服务器训练/评估场景不同，不能直接把结果当成同场景复现。
- 普通地面和楼梯 friction 为 `1.05 / 0.006 / 0.0001`；地面 condim=4，滚动摩擦项不生效。地形生成器包含的其他区域保留原参数。
- 名义测试关闭训练随机化、观测噪声和 0..4 步执行器延迟，自碰撞关闭。reset 使用默认姿态，上一 action 为零、首帧历史重复填充。
- 键盘：W/S 前后、A/D 平移、Q/E 转向，松键对应轴归零；U/J 三轴联动调速，初值 0.8，保留当前 CTS 上限 `[1,1,1.5]`；空格清零，R 重置，1/2/3/4 切换楼梯。

`verify_mujoco.py` 执行 3 秒零命令，以及 2 秒零命令预热后各 5 秒前进 0.5 m/s、横移 0.3 m/s、自转 0.5 rad/s。每项使用独立仿真实例，报告位于 `verification/smoke_*.json`，汇总见 `verification/mujoco_smoke_summary.json`。这些测试检查加载、接口和有限状态，完整楼梯运动质量仍需观察。

服务器固定楼梯评估 `97/144` complete，`release_accepted=false`；原始报告保存在 `training_records/server_evaluation/`。这是固定用例结果，不是随机化通过率。本包用于本地仿真，未连接实机。
