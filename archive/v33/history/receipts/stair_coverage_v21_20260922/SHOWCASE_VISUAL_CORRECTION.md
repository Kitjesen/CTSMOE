# 33865 楼梯视频遮挡错误核查

## 确认的原因

旧 CPU 轨迹回放器在同一原点保留了 L6 与 L9 两份可见楼梯网格。渲染每个 case 时没有选中对应地形，另一份网格遮挡了腿和轮子。旧三分屏又按426像素步长粘贴640像素画面，发生覆盖和裁切。

原先的关节正运动学与单个地形射线验证没有覆盖最终组合场景，因此不能证明旧视频显示正确。旧 `stairs_up.mp4`、`stairs_down.mp4`、`stairs_up_three.mp4`、`stairs_down_three.mp4` 保留为错误证据，撤销视觉验收用途。第一次 `*_visualfix.mp4` 也不作为最终交付，最终修订需验证场景隔离和成片一致性。

## 影响范围

回放器只读取原 Isaac 轨迹，不执行物理步进，不参与奖励、碰撞或策略训练。该显示错误不改变 V20 原始评估指标，也不改变当前 V21 更新。重做视频用于修正展示，不能当作策略能力改善。

## 最终交付要求

每个分屏只允许对应等级地形出现在相机和地面射线中；验证分割图无非本等级地形像素。三分屏保持原相机宽高比并使用互不覆盖的区域。保存源代码、轨迹、成片哈希与场景检查结果；原速、原 case、原终止帧不变。最终文件及验证见后续 `SHOWCASE_CORRECTION.json`。
